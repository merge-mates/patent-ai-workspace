# 0002. 3주 첫 결과물의 구현 범위

## 상황
기획서에는 조사 세 가지(법률 조사, 선행기술 조사, 기술·경쟁사 조사)와 국내 OA 대응이 있다. 이전 기획서(v3.0)는 선행기술 조사를 먼저 깊게 만들 대상으로 두었다. 한편 기획은 OA 대응 흐름을 먼저 구체화했고, 실제로 확인한 데이터도 OA 쪽(OA PDF 4건)이 가장 많았다. 2명·3주로 모두 할 수 없어서 첫 결과물을 골라야 한다.

## 비교한 선택지
| 안 | 지금 자료로 가능한 것 | 먼저 풀 관문 |
|---|---|---|
| OA 대응 | OA 원문 위치가 붙은 구조 추출, 청구항–인용문헌 대비 | 사람이 검수한 필드 정답, OA 당시 청구항 확보, 인용 원문 위치, 이용 권한 |
| 선행기술 조사 | 작은 비전 문헌 묶음에서 청구항 기반 후보 검색, 구성요소–문단 대비 | 분야 문헌 묶음·기준일, 정답이 여럿인 문제, 이용 조건 |
| 법률 조사 | 법령·심사기준 로컬 검색, 판본·근거 위치 표시 | 판본 날짜 불일치, 과거 사건 시점 판본, 새 정답 |

## 결정
확정 (2026-11-13).
- 조사 중 집중 대상은 **법률 조사**다. 기술·경쟁사 조사와 선행기술 조사는 기획서에 두되 구체화하지 않는다.
- 3주 첫 결과물: **OA 대응 흐름 안에 법률 조사를 연결**한다. OA 읽기·거절이유별 정리 → 청구항–인용문헌 대비 → 지적마다 법률 근거 조사(대화, 같은 기능을 사건 없는 질문에도 씀) → 대응 방향 후보 2~3개(11/16·11/17 보완으로 바뀜: 거절이유별 단위마다 순위·이유·확신도, [ADR 0001](0001-ai-amended-claim-draft.md)) → 고른 방향의 의견서·검토용 보정 청구항 초안. 시연 가치를 우선해 초안까지 넣는다. 세부는 [product.md](../product.md).
- 인용문헌은 한국·미국만. 첫 지원 거절이유는 의견제출통지서 학습데이터로 빈도를 본 뒤 정한다 (11/15 진보성·명확성, 11/17 신규성 추가로 정함 — [product.md](../product.md) 3.2절).
- 고르지 않은 안: 법률 조사만 깊게, OA 대응만 깊게. 흐름이 반쪽이라 시연 설득력이 작다.

2026-11-16 보완 (팀 확정): 범위는 그대로이고 줄이는 것 없음. F2·F3에 지식 그래프 검색 층(가져온 이유를 관계 경로로 보임)과 중요한 단계마다 검증을 더한다. 대응 방향 후보의 모양은 ADR 0001 11/16 보완을 따른다.

## 결과
- 흐름이 길어 3주 위험이 크다. 줄일 순서: 보정 초안 → 단독 법률 질문 입구 (product.md 10절).
- 필요한 자료는 기능별로 다시 받는다 (product.md 8절).
