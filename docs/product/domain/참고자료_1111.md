# 특허 도메인 지식과 참고자료

기준일 2026-11-11. 기획 참고용이며 법률 자문이나 확정 규칙이 아니다. 공식 법령·심사기준, 실무 설명, 제품 설명을 구분하고 적용 시점과 판본을 확인한다. 공개 열람은 저장·학습·재배포 권한을 뜻하지 않는다.

## OA와 거절이유별 검토

- [특허·실용신안 심사기준 공식 목록](https://kipo.go.kr/ko/kpoContentView.do?menuCd=SCD0200146) — 2026-11-11 확인 당시 2026-03-12 기준 안내. 과거 심사절차 PDF(exammanual_05_1)는 2006·2009년 추록이 포함된 역사 자료로, 현행 기준 근거로 사용하지 않는다. 해당 구체 항목의 최신 내용은 별도 대조 필요.
- [특허법 제62조](https://law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1028030821) — 공식 법령 특정 판본, 확인 2026-11-11. 거절이유를 여러 법 조항에 걸쳐 규정하며 블로그의 네 가지 설명으로 전체를 한정할 수 없다. 사건별 적용 법령의 시점·시행 여부 확인 필요. 제품의 유형 분류와 법률 조항 분류는 같다고 가정하지 않는다.
- 의견제출통지서 대응 — 특허법률사무소 설명, 2026-10-08, 확인 2026-11-11. 신규성·진보성·기재불비 등의 대응 관점, 구성요소 대비 예시와 의견서·보정서 선택 사례. 유형별 다른 검토 필요성을 보여주는 참고이며 사례를 자동 법률 규칙으로 사용하지 않는다. 기한·보정 범위는 당시 공식 법령과 실제 통지서를 확인한다.
- [지식재산처 특허 이해](https://www.kipo.go.kr/ko/kpoContentView.do?menuCd=SCD0200111) — 공식 절차 개요, 확인 2026-11-11. 의견·보정 및 심사 흐름 참고.
- 의견제출통지 대응 — 변리사 실무 설명, 2026-10-02, 확인 2026-11-11. 거절이유·문헌 비교와 권리범위 유지의 중요성을 설명한다.

## 보정과 의견서

- [특허법 제47조](https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=279827) — 공식 법령의 특정 판본. 보정 시기·최초 명세서 범위 등은 사건에 적용되는 판본과 시행 여부를 별도 확인.
- [특허로 의견서 작성 사례](https://kporc.kipo.go.kr/smart/manuals/KIPO_PatentApplicationDocumentExample.pdf) — 공식 사례, 확인 2026-11-11. 사건·제출인·발송번호 및 서식 확인에 참고. 모든 사건의 완성 템플릿은 아님.
- [특허로 명세서작성기 설명서](https://www.patent.go.kr/smart/docs/download/MOIPEditorManual.pdf) — 공식 도구 설명, 확인 2026-11-11. FIN 보정 및 DTA 별지 생성 참고. 우리 서비스의 생성·호환성은 미검증.

## 유사 서비스 — 공개 제품 설명

- 국내 OA 대응 AI 서비스 제품 설명 — 분석·구성 대비표·전략 선택·초안과 출력 참고. 업체 설명이며 독립 성능 검증이나 사용자 선호 조사로 취급하지 않는다.
- 해외 OA 대응 AI 서비스 제품 설명 — 거절이유 분석·자료 병렬 확인·편집 참고. 국내 OA 지원은 이 자료에서 미확인.
- 선행조사 AI 서비스 제품 설명 — 선행조사와 근거 추적 참고. OA 전용 흐름의 직접 근거는 아님.

## 지속적인 조사 원칙

사용자 흐름·기능 설계에서 실무 관행이나 법률 요건에 의존할 때 공개 자료를 검색하고 핵심 발견·출처·확인일·한계와 기획 의미를 함께 기록한다. 실무 사례를 보편적 규칙으로 바꾸지 않고 필요 시 당시 공식 법령·심사기준을 확인한다.
