## 표본 OA에서 확인한 것 (공식 문서)

KIPRIS Plus로 받은 OA 원문 표본을 열어 봤다. 원문은 git에 올리지 않는다.

- OA 첫 장에 **발송일자·제출기일**이 찍혀 있다. 2022-03-22 발송 → 제출기일 2022-05-22 (2개월). 안내문: 지정기간연장으로 늘릴 수 있고, "4개월을 초과하여" 늘리려면 소명서가 필요. (10-2020-7035296 OA, 공식 문서)
- 2018-08-14 거절결정서 안내: 재심사·심판 청구 "30일 이내". 지금(2022-04-20 이후)은 3개월. → 같은 종류 문서라도 발송 시점에 따라 안내가 다르다. (10-2017-0011929 거절결정서, 공식 문서)
- OA 구성: `[심사결과]` → 심사 대상 청구항 → "거절이유가 있는 부분과 관련 법조항" 표(순번·청구항·조문) → `[구체적인 거절이유]` → 안내문. 표본 3건 모두 "최후"라는 말이 없다 (모두 최초거절이유통지). **최후거절이유통지가 원문에 어떻게 표시되는지는 최후거절이유통지 표본을 구해야 안다.**
- 실제 흐름 예 (10-2020-7035296 행정 이력): OA(2022-03-22) → 기간연장 신청(05-18) → 보정서+의견서(06-20) → 거절결정(10-26) → 재심사 보정서+의견서(11-23) → 다시 거절결정(2023-02-20). 거절결정 뒤 재심사까지 이어지는 실무 흐름이 실제로 있다.
- 10-2021-7043357은 행정 이력에 의견서(2022-05-27)가 있다.
