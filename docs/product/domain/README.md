# 도메인 지식 목차

3주 PRD(`docs/product.md`)를 만들 때 필요한 특허 실무 지식. **주제마다 한 파일**, 파일마다 출처·출처 종류·확인일·한계를 붙인다 (`docs/README.md` 규칙). 기획 참고용이며 법률 자문이 아니다.

**쓰는 법:** 법적 날짜·기간·요건은 공식 자료(법령, 지식재산처, 판례, OA 원문)로만 쓴다. 사무소 블로그·개인 글은 업무 흐름 이해용이다 (팀 규칙). 저장소에는 공식 자료(법원·법령·지식재산처·KIPRIS) 링크만 두고, 블로그·사무소·회사 글은 날짜와 출처 종류만 적고, 사무소·회사·글쓴이 이름은 적지 않는다.
