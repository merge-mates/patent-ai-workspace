# Phase 6 실험 결과: 청킹 단위 × 질의 확장 (새 개발 47문항)

작성: 2026-11-13. 상태: 실험 ①②③ 완료(7장이 ③, 8장이 LLM 재순위), 봉인 평가 완료(9장). 봉인 세트는 9장에서 한 번 평가했다.

## 1. 평가 세트
- 개발 47문항 `data/eval/questions_d2_dev.jsonl`: 독립 작성자가 쓴 변리사 질문 + 에이전트 2명이 따로 지정한 정답의 교집합. 주 정답 기준 특허법 29·시행령 11·시행규칙 7. 정답이 여러 조문이면 하나만 맞아도 적중.
- 시행령 질문 중 상당수(V계열)는 **조문 제목 목록을 본 작성자**가 썼다(제목 단어는 쓰지 못하게 함). 완전한 독립이 아니고 쉬울 수 있다.
- 질문 1개 = 2.1%p. 판정 규칙(기존): 3문항 이상 차이 + 설명 가능할 때만 "낫다", 아니면 "차이 없음".

## 2. 비교한 것
- 청킹 단위: **조문**(502청크) / **항**(1,331청크, 긴 호는 3000자 분할) / **혼합**(조문 502 + 항만 있는 1,152 = 1,654청크).
- 질의 확장: **없음** / **v1**(기존, "일상어 → 특허법 조문 용어") / **v2**(새, "변리사 실무 용어·약칭 → 특허법·시행령·시행규칙 조문 용어", 예시 없음, 모델 gpt-5.4-mini-2026-03-17, 개발 결과를 보기 전에 작성).
- 검색: M2a(키워드) / M3(임베딩 3-small) / **M4a(하이브리드)**. 아래는 M4a 위주.

## 4. 판정
- **질의 확장 있음 vs 없음: 확장이 낫다.** M4a에서는 단위와 관계없이 Hit@1이 +2~+8, MRR이 +0.08~+0.12 올랐고(조문 20→28, 항 21→26, 혼합 22→25), 순위가 좋아진 질문이 나빠진 질문의 2~3배(예: 항 17개 대 6개; M2a는 항 단위에서 Hit@1이 23→24로 거의 그대로였다). 변리사 말투의 질문에서도 효과가 유지됐다.
  - 단, 질문 작성자(Claude)와 확장 모델(GPT)이 모두 LLM이라 문체가 비슷할 수 있고, 질문이 실제 변리사 질문이 아니다. 실제 사용자 질문에서의 효과는 미확인.
- **v1 vs v2: 차이 없음.** 순위가 좋아진 질문과 나빠진 질문이 비슷하다(조문 8 대 9, 혼합 7 대 10, 항 9 대 6). MRR은 v2가 조문 +0.034, 항 +0.010, 혼합 +0.008이지만 Hit@5는 조문 -2, 혼합 -2. 확장어를 열어 보면 단어 몇 개가 달라진 정도(예: V23·V27)라 모델 응답 차이로 보인다. 같은 설정을 반복 실행한 변동 폭은 측정하지 않았다.
- **조문 vs 항 vs 혼합: 차이 없음.** M4a v2에서 Hit@1은 조문이 앞서고(28 대 26) Hit@5는 항이 앞서(42 대 39) 엇갈리며 MRR은 0.703으로 같다. 항 단위가 새로 5위 안에 넣은 질문(N01, N02, N21, N36)과 잃은 질문(S32)이 있으나 기준(3문항 이상 + 설명)을 일관되게 넘지 않는다. 혼합은 v1에서 Hit@5 43으로 가장 높았지만 v2에서는 41이다.
  - 이전 개발 32문항에서는 항 단위가 좋았고(16/23/25 대 11/21/24) 이번 세트에서는 차이가 없었다. 이번 세트도 "비슷함"이어서, 검색 정확도만으로는 어느 쪽도 고를 근거가 없다.
- **M4a 하이브리드 vs 단독:** 확장이 있을 때 M4a가 M2a보다 크게 낫지 않다(조문 v1 M2a MRR 0.712 대 M4a 0.669). 이전 결과(M4a가 가장 좋음)와 달리 이 세트에서는 하이브리드 이득이 불분명하다.

## 7. 실험 ③: 법령 간 경쟁 해결 (기준 = 항 단위 + 확장 v2 + M4a: 26/39/42, MRR 0.703)

### 7-1. 실패 분석(실험 전)
기준에서 1위가 아닌 21개 질문의 1위 조문: 다른 법령 조문 10개(정답이 특허법인데 시행규칙이 1위 5개: N02, N15, N21, N54, S32 / 정답이 시행령인데 특허법·시행규칙이 1위 5개: V05, V15, V17, V21, V27), 같은 법령의 다른 조문 11개(인접 조문 N35·N42, 비슷한 서식 조문 S37 등). 두 방향이 섞여 있어 "법 우선" 같은 일률 규칙은 한쪽을 고치면 다른 쪽을 망칠 것으로 예상했다(가설).

### 7-4. 판정
- **law_first: 나쁘다(채택하지 않음).** 특허법이 정답인 질문 6개는 고쳤지만(N02, N15, N21, N36, N54, S32) 시행령·시행규칙이 정답인 질문 15개가 밀렸다. 예상대로의 맞교환이고 순손실이 크다. 법령 간 경쟁은 "법 우선"으로 풀 수 없다.
- **link_pairs: 차이 없음.** 올라간 질문 2개, 내려간 질문 1개. 법·시행령 짝이 대개 이미 2~3위에 있어 순서를 바꿀 여지가 작다. 해가 없고 규칙이 단순해 나중에 "근거 묶음 표시"에 쓸 수는 있지만 검색 성능 근거는 아니다.
- **context: 차이 없음.** 좋아진 질문 8개와 나빠진 질문 8개로 상쇄된다. 이득이 일관되지 않다.
- 한계: 개발 47문항 하나로만 봤고, 같은 호출 반복 변동은 재지 않았다. 1~3문항 차이는 잡음일 수 있다.

### 7-5. 남은 실패와 시사점
- 남은 5위 밖(N35, S32, S37, V21)과 Hit@1 실패 대부분은 인접·유사 조문끼리의 경쟁이라, 순서 규칙이나 문맥으로는 안 풀렸다. 이를 줄일 후보는 LLM 재순위(질문마다 호출 1회 추가, 비용·지연 발생)뿐이다.
- 챗봇은 상위 5~8개를 LLM에 넘기므로 Hit@1보다 Hit@5·Hit@8이 중요한데, 기준의 Hit@5는 47개 중 42개이고 정답이 2~4위에 있는 질문이 많다. 답변 단계에서 근거를 얼마나 잘 고르는지가 다음 병목일 수 있다(미검증).

## 8. 실험 ③-d: LLM 재순위 (기준 = 항 단위 + 확장 v2 + M4a)

### 8-1. 방식(결과를 보기 전에 고정, 프롬프트 v1 한 번, 개발 결과를 보고 고치지 않음)
M4a가 낸 상위 10개 조문의 본문(항 청크는 합치고 머리글 한 번, 1,500자까지)을 **원 질문**(확장 전)과 함께 gpt-5.4-mini-2026-03-17에 보여 주고, 질문에 직접 답하는 순서대로 후보 번호를 다시 나열하게 한다(temperature 0). 11위 이하는 그대로. LLM에는 정답·평가 정보를 넣지 않는다. 질문마다 호출 1회 추가. 구현: `src/retrieval/llm_rerank.py`, 러너 `--llm-rerank-model`.

### 8-2. 결과 (Hit@1/3/5, MRR)
| 구성 | 재순위 없음 | 재순위(1회차) | 재순위(2회차) |
|---|---|---|---|
| 항 단위 | 26/39/42, 0.703 | 40/44/45, 0.899 | 41/45/45, 0.915 |
| 조문 단위 | 28/38/39, 0.703 | 34/41/41, 0.805 | - |

- 같은 설정을 두 번 돌렸을 때 47개 중 45개의 순위가 같았다(변동 폭: Hit@1 40~41). 순위가 좋아진 질문 17개, 나빠진 질문 3개(N12, V17, V18).
- 법령별(항 단위, 재순위 1·2회차 Hit@1/3/5): 특허법 29개 기준 19/24/27 → 27/28/28, 시행규칙 7개 1/5/5 → 4/6/6, 시행령 11개 6/10/10 → 9/10/11(1회차), 10/11/11(2회차). 시행령·시행규칙도 같이 좋아졌다.
- 후보 풀 한계: 기준 M4a의 상위 10 안에 정답이 있는 질문은 항 단위 45개, 조문 단위 41개. 재순위의 Hit@5(45, 41)는 이 한도에 도달했다. 풀 밖인 질문(S37, V21 등)은 재순위로 못 고친다.
- 항 단위가 조문 단위보다 재순위 후 더 좋은 것(Hit@1 40~41 대 34)은 후보 풀 재현율(45 대 41) 차이로 보인다. 이 지표(Hit@10)는 사전에 정한 것이 아니라 사후 확인이라 참고용이다.

### 8-3. 판정과 한계
- **이득이 크고 반복해도 유지된다**(Hit@1 26 → 40~41, MRR 0.703 → 0.90~0.92; 질문 1개 = 2.1%p인데 14개 이상 차이). 규칙상 "낫다"에 해당한다.
- **해석 주의:** (1) 정답은 LLM 에이전트 2명이 지정한 것이라, "직접 답하는 조문"에 대한 LLM의 판단이 정답 기준과 비슷하게 치우쳐 있을 수 있다. 사람 전문가 판단으로 확인한 것이 아니다. (2) 질문도 LLM이 썼고 확장·재순위 모델이 같은 계열이다. (3) 개발 47문항 한 세트이며 봉인 세트로 확인 전이다. (4) 질문당 LLM 호출이 1회 늘고 프롬프트가 길다(후보 10개 본문). 지연·비용은 측정하지 않았다.

### 9-3. 한계 (결과가 좋아 보여도 이 점은 그대로 남는다)
- 정답을 지정한 것도 LLM 에이전트 2명이고, 질문도 LLM이 썼으며, 재순위·확장 모델도 LLM이다. 사람 전문가가 같은 정답을 인정하는지는 확인하지 않았다.
- 봉인 25문항은 개발 47문항과 같은 방식으로 만든 같은 분포의 질문이다. 실제 변리사가 쓰는 질문, 모호하거나 지저분한 질문에서의 성능은 모른다.
- 시행령 질문 일부는 조문 제목을 본 작성자가 썼다. 정답이 복수인 질문은 하나만 맞아도 적중이다.
- 검색 상위 10개 안에 정답이 없으면 재순위로 못 고친다. 질문당 LLM 호출이 확장 1회 + 재순위 1회 늘고, 지연·비용은 측정하지 않았다.
- 정답이 없는 질문(코퍼스 밖 질문)에서 "근거 없음"을 잘 판단하는지는 이번 평가에 포함하지 않았다(생성 단계에서 평가).
