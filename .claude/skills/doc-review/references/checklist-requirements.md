# 기능 명세(docs/features/<기능>/requirements.md) 체크리스트

- [ ] 무엇을 하는지 두 줄 이내 (사용자 말로)
- [ ] product.md의 어느 줄에서 왔는지 링크
- [ ] 합격 기준이 3~7개, 각각 **테스트로 바꿀 수 있다** (입력 → 기대 결과, 또는 숫자 문턱)
- [ ] AI 기능이면 점수 기준(어느 평가 세트, 어떤 점수, 문턱)이 있다
- [ ] 안 할 것이 1줄 이상
- [ ] 화면이 있으면 화면 흐름 한 줄, API가 있으면 엔드포인트 이름 한 줄
- [ ] 주인(사람)과 리뷰어가 적혀 있다
- [ ] 비교 실험 여부(예/아니오)와 비교할 축
- [ ] 다른 기능에 기대는 것(먼저 끝나야 하는 것)
- [ ] 10줄 안팎. 설계(어떻게)가 섞이지 않았다 → 섞였으면 design.md로
