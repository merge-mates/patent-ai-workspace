# 기획안(docs/product.md) 체크리스트

## 문제와 사용자
- [ ] 누가(구체적인 사람 한 명으로 그려지나) 어떤 일에서 무엇이 불편한지 한 문단으로 있다
- [ ] 지금은 그 일을 어떻게 하는지(대안)가 있다
- [ ] 이 제품이 없으면 무엇이 깨지는지 말할 수 있다

## 범위
- [ ] 기능 목록이 5~8개 이하이고 각 기능이 한 줄로 설명된다
- [ ] "안 할 것"이 3줄 이상 있다
- [ ] 11/27 시연에서 보여 줄 흐름 하나가 처음부터 끝까지 적혀 있다
- [ ] 기능마다 담당(사람 이름 또는 같이)이 있다

## AI 부분
- [ ] AI가 하는 일과 규칙(코드)으로 하는 일이 나뉘어 있다
- [ ] AI 결과가 맞는지 무엇으로 재는지(평가 세트, 채점 방법) 한 줄이 있다
- [ ] 비교 실험할 후보가 있으면 무엇을 비교하는지 적혀 있다

## 데이터·외부 API
- [ ] 쓰는 데이터 출처(외부 API, 받은 자료)와 이용 조건·호출 상한이 있다 (출처 링크)
- [ ] 비공개 샘플을 어디에 두고 무엇을 하지 않는지 있다
- [ ] 비용 상한(모델 API 월 얼마)이 있다

## 위험
- [ ] 가장 큰 위험 3개와 대처가 있다
- [ ] 재 보지 않은 숫자는 `[가정]` 표시가 있다

## 문장
- [ ] "적당히", "등", "나중에" 같은 말이 결정을 숨기지 않는다
- [ ] 출처와 출처 종류가 있다 (없으면 "출처 없음, 판단")
