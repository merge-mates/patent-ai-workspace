# 법령 질의 낱말을 나온 만큼 세면 (근거 남기기)

**가설**: bm25s 기본 셈(질의에 같은 낱말이 나온 만큼 셈)이면 긴 거절이유 질의에서 흔한 두 글자가 반복돼 점수가 떨어진다. 법령 설정을 `unique_query_terms: true`로 둔 근거.
**종류**: 설정 비교
**바꾼 것 (하나)**: `unique_query_terms` true → false. 나머지 설정·색인은 기준선과 같다.

## 해석
- 기준선 카드에 숫자로만 적었던 0.211을 scores.json으로 남겼다 (결정적 계산이라 다시 돌려도 같다).
- 법령은 `unique_query_terms: true`를 쓴다. hit@10은 같아 정답은 상위 10 안에 남지만, 1~5위를 흔한 낱말이 많은 조문이 차지한다.
