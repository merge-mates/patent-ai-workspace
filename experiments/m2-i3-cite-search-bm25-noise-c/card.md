# 인용문헌 검색 둘째 점수 (노이즈 C안, 판 2)

**가설**: 정답과 같은 분야·비슷한 낱말의 공보(C안)를 섞으면 상관없는 인용문헌(B안)만 섞을 때보다 문단 Hit@k가 더 내려가고, 검색 방식(BM25·벡터·하이브리드) 사이 차이가 드러난다.
**종류**: 평가 범위 비교 (검색기는 m2-i2 설정 그대로)
**바꾼 것**: 줄마다 검색 범위와 색인. 정답은 그대로(tune v2, 68줄). 판 3(11/23) 전에 먼저 쟀다 (재아 요청: OA를 늘릴지 일찍 정하려고).

## 결과 (n=68, 11/22, 비용 0)

## 해석 (11/22 은진·Claude, 재아 확인 전)
- C를 더하면 세 방식 모두 Hit@10이 조금 더 내려가고(BM25 −0.03, 벡터 −0.02, 하이브리드 −0.04), 문헌 Hit@1이 더 크게 내려간다(−0.04~−0.07). 비슷한 공보가 1등 조각을 가져가는 것이 C의 효과다.
- C 범위에서 벡터·하이브리드(0.338)가 BM25(0.265)보다 Hit@10이 0.07(68줄 중 5줄) 높다. 다만 n=68에서 Hit@10 0.3 근처의 95% 구간은 대략 ±0.11이라 이 차이도 우연과 구분되지 않는다. 짝지은 비교(같은 줄끼리, `eval.retrieval.compare`)는 아직 안 했다.
- 그래서 문헌(노이즈)을 더 늘리기보다 평가할 질의(OA) 수를 늘려야 방식 차이를 볼 수 있다는 11/22 은진·재아 판단과 맞는다. 판 3(tune 30건 정답)으로 다시 잰다.
- 노이즈 상위 오답 확인은 아래 절 (#178 T4).

## 노이즈 상위 오답 확인 (11/22, #178 T4)
하이브리드 C 범위에서 상위 10에 정답 위치가 없던 45줄 중, 상위 10에 노이즈 문헌 조각이 든 37줄을 봤다. 줄마다 가장 위 노이즈 조각 하나(33줄은 1등). 노이즈 조각이 그 청구항 구성요소를 실제로 보여 주는지 관련/일부/무관으로 판정했다.
- 판정한 쪽: 이 실험 맥락을 모르는 Claude 에이전트 3개가 따로 (표 하나만 주고 다른 파일·서로의 판정은 못 봄). 사람 판정이 아니다. 판정 기준·심사관이 짚은 문단은 같은 표에 줬다.
- 일치: 셋 다 같음 31/37, 둘씩 0.86~0.92.

| 다수결 | 줄 수 | B 노이즈 (다른 사건 인용문헌) | C 노이즈 (비슷한 공보) |
|---|---|---|---|
| 관련 | 2 | 2 | 0 |
| 일부 | 16 | 13 | 3 |
| 무관 | 19 | 11 | 8 |

- 노이즈가 차지한 상위 오답은 거의 진짜 오답이다. "관련" 2줄(셋 다 관련)을 맞힌 것으로 쳐도 하이브리드 C Hit@10은 0.338 → 약 0.368이라 위 결론(방식 차이는 우연과 구분 안 됨)은 그대로다.
- C 공보는 관련 0줄: 같은 IPC·비슷한 낱말이라도 구성요소를 보여 주는 문단은 아니었다. 검색을 헷갈리게 하는 그럴듯한 오답 역할만 한다.
- 표(질의·조각 글·판정, git 밖): `work/t4_review/hybrid_c_top_noise_judged.csv` (은진 맥).
