# 법령 BM25를 Kiwi 형태소로

**가설**: 형태소로 자르면 조사·어미가 빠져 드문 낱말이 더 또렷해져 hit@1이 오른다.
**종류**: 설정 비교
**바꾼 것 (하나)**: `settings.tokenizer` char_bigram → kiwi (`pos_tags` 칸이 같이 생김, kiwi에만 쓰임)

## 결과 (scores.json)
| 지표 | 기준선 (char_bigram) | 이번 (kiwi) | 차이 |
|---|---|---|---|
| hit@1 / @3 / @5 / @10 | 0.632 / 0.947 / 1.000 / 1.000 | 같음 | 0 |
| recall@1 | 0.605 | 0.632 | +0.026 (항목 하나) |
| recall@5 | 0.974 | 0.974 | 0 |
| 비용($) / 외부 호출 | 0 / 0 | 0 / 0 | |

- n = 19줄. 11.9초 → 17.5초 (Kiwi 분석).
- 순위 내용은 다르다: 19줄 중 상위 10 목록이 같은 줄 0개, 1위 조각이 같은 줄 9개.

## 실패 유형 (개수)
| 유형 | 기준선 | 이번 |
|---|---|---|
| excluded_* 전부 | 0 | 0 |
| CQ 후보 | 0 | 0 |

## 해석
- 이 tune 세트(19줄, hit@5가 이미 1.0)는 두 낱말 자르기를 가를 힘이 없다. 어느 쪽이 낫다고 말할 수 없다.
- 같은 기준으로 두 말뭉치를 보려면 kiwi로 맞춰도 법령 점수를 잃지 않는다. 대신 1.5배 느리다.
