## 해석 (Claude 초안, 재아 확인 11/21)
- 보려던 것은 됐다: 빈 객체 7 → 0, 칸 제목 2 → 0, 지어낸 값 0 유지.
- 주 지표는 예측 없음 3건 때문에 낮다. 예측이 있는 사건끼리는 앞 실행과 같은 수준이고 차이는 같은 설정의 흔들림 안이다. 이 실험만으로 점수가 올랐다·내렸다고 말할 수 없다.
- 채택 여부(판단): 프롬프트의 모순을 없앤 것이라 채택 쪽. 정하는 것은 사람.
