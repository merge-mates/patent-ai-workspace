# 인용문헌 하이브리드 (RRF)와 세 방식 비교

**가설**: BM25와 벡터가 서로 다른 줄을 맞히므로(벡터 카드 순위 이동), 순위로 섞으면 둘 중 어느 쪽보다 같거나 낫다.
**종류**: 구현 비교 (같은 인터페이스, 검색 방식만 다름)
**바꾼 것 (하나)**: 검색 방식 `bm25` → `hybrid`. 안쪽 BM25 설정은 bm25-v2와 같은 값, 안쪽 벡터는 벡터 실험과 같은 기록된 질의 벡터.

**남겨 둘 설정**: 임베딩 text-embedding-3-small (1536차원), RRF `rrf_k`=60 (Cormack·Clarke·Büttcher, SIGIR 2009, 학회 논문), 가중치 0.5/0.5 (11/20 재아). 안쪽 k = 범위 안 조각 전부.

## 해석 (사람이 고칠 것)
- 하이브리드가 모든 k에서 BM25·벡터 이상이다. 다만 상위 10에서 갈린 줄은 하이브리드만 8 대 BM25만 2 (부호 검정 p≈0.11, 줄 부트스트랩 95% 구간 0.000~+0.176), 하이브리드 대 벡터는 4 대 3 (p=1.0) (experiment-analyst 계산, 판단). "이 tune 세트(한국 공보 중심)에서 하이브리드가 BM25보다 나빠지지 않고 조금 나은 쪽"까지만 말할 수 있다.
- 68줄은 출원 8건·문헌 16개에서 나와 독립이 아니다. 위 p·구간은 실제보다 낙관적이다.
- 논문 6줄은 세 방식 모두 Hit@10 1.000이라 방식 차이를 말할 수 없다.
- 세 방식 공통 CQ 15줄은 검색 방식보다 질의(청구항 전문)·정답 정의 쪽을 먼저 의심해 볼 만하다 (판단).
- [사람 판단] 채택(F3 기본 검색 방식)은 세 방식 표를 보고 재아가 정한다 (문턱 없음, design 8절).
