# 대비 차이 후보로 명세서 질의 좁히기

[추적 이슈 #345](https://github.com/merge-mates/patent-ai-workspace/issues/345) · 2026-11-24 · tune 4건 탐색.

같은 사건의 최초 명세서 조각, BM25, 상위 10개, 상세 골드 10행을 고정했다. 질의를 바꾼 행은 7개다. 전체 청구항 → 대비 차이 후보 조건에서 Recall@10은 0.317 → 0.217, MRR@10은 0.104 → 0.076, 상위 10개 적중 행은 5/10 → 4/10이었다. 차이 후보만으로 기존 질의를 대체하기 어렵다. 답변 또는 수정 청구항 생성은 같은 조건으로 다시 돌리지 않았다. 보정 조건을 별도로 작성하는 질의는 다음 비교에 포함한다.

`work/e2e_2026-11-24_oa4`의 동결 입력으로 `focused_probe.py <기준선 폴더> <새 출력 폴더>`를 실행한다. 로컬 출력의 OA별 Markdown·JSONL에는 두 실제 질의와 순위, 기대 골드를 보관한다.
