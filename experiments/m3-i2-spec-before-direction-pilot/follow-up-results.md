# OA 네 건 후속 실험 기록

2026-11-24 · [추적 이슈 #345](https://github.com/merge-mates/patent-ai-workspace/issues/345). 이 문서는 결과의 방향과 관계없이 완료한 비교를 기록한다. 실제 OA 원문, 사건 식별자, 질의별 원문 결과, 모델 원응답은 로컬에 보관한다.

## F2·F3 실행 순서

기준 `96887ae`. F2가 저장된 F1 결과와 준비된 판단 단위로 실행되도록 분리했다. A는 F3→F2, B는 F2→F3이다. OA 4건에서 각 조건을 4회 실행한 16쌍에서 두 단계의 결과 JSON과 보류 목록이 모두 일치했다. F2는 조건별 판단 단위 13/13개에 법률 근거 묶음을 반환했다. 백엔드 테스트 715개가 통과했다.

B에서는 법률 근거 준비 시점이 짝별 중앙값 9.875초 앞당겨졌다. 두 단계 전체 시간의 B−A 차이 중앙값은 −0.035초였고 범위는 −1.897~+0.772초였다. 로컬 색인은 실제 검색했다. F3의 Anthropic `claude-haiku-5-5` Medium 응답과 Google `gemini-embedding-001` 1536차원 임베딩은 저장본을 재생했다. F2의 조문 조회와 BM25에는 모델 호출이 없었다. 결과가 지지하는 것은 법률 근거의 조기 준비와 이 표본에서의 결과 동등성이다. 법률 자료를 F3 프롬프트에 전달하는 조건은 별도 검증이 남아 있다.

## F3 다시 찾기

기준 `96887ae`, tune v2 OA 네 건. 검색 기록 185행과 모델 캐시 66개에서 동일한 1차 후보·판정과 근거가 없는 구성요소·인용문헌 31쌍을 복원했다. 동일 스냅샷으로 각 조건의 2차 검색을 두 번 실행했다. 점수 분모는 공통 대상에 대응하는 골드 11행이고, 시간은 네 사건에 대한 2차 검색의 합계다.

| 조건 | 회수율 1·2회 | 최종 선택률 1·2회 | 모델 호출 1·2회 | 임베딩 전송 1·2회 | 시간(초) 1·2회 |
|---|---:|---:|---:|---:|---:|
| A 기존 2차 검색 | 86.6% / 86.6% | 27.6% / 23.5% | 10 / 9 | 18 / 18 | 143.79 / 125.76 |
| B 질의 재작성 | 89.2% / 87.8% | 29.0% / 23.5% | 63 / 63 | 93 / 93 | 303.78 / 297.37 |
| C 도구 호출 에이전트 | 89.2% / 90.4% | 29.0% / 29.0% | 170 / 172 | 47 / 53 | 385.86 / 392.32 |

대비·재작성·도구 선택은 Anthropic `claude-haiku-5-5` Medium, 질의 임베딩은 Google `gemini-embedding-001` 1536차원, 색인은 `cite-idx-v5`를 사용했다. C는 B 대비 첫 회차에 선택률이 같았고 둘째에 5.5%p 높았으며, 모델 호출은 약 2.7배였다. 대표 사례에서 B는 골드 문단 하나를 검색에서 놓쳤고 다른 골드 도면은 검색 후 재판정에서 빠뜨렸다. 검색 누락과 선택 누락을 구분해 기록한다. 이 네 건으로 에이전트를 기본값으로 채택할 정도의 재현성이나 비용 대비 효과는 확인하지 못했다.

| 비교 | 결과와 분모 | 해석 범위 |
|---|---|---|
| v5 전체 청구항 질의 | BM25·벡터·하이브리드 Recall@5 33.0%·34.6%·36.2%, Recall@10 46.5%·59.1%·54.8%. 골드 위치 확보율 153/164, 조건부 채점 68행 | 같은 질의 및 문헌 범위의 순위 비교 |

| 저장 초안 채점 | 조건당 동일한 37개 논점. 직접·부분·누락은 기존 5·7·25, BM25 5·10·22, 검수 문단 전달 4·9·24 | OpenAI GPT-6.2 Sol High의 같은 Codex 세션에서 조건명을 가리고 한 번 평가했다. 일부 상류 메타데이터가 노출됐고 사람 판정 일치도는 미측정 |
