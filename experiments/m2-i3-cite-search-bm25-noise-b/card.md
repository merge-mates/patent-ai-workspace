# 인용문헌 BM25 둘째 점수 (노이즈 B안)

**가설**: 정답 인용문헌 하나 안에서만 찾던 범위에 다른 인용문헌(노이즈)을 섞으면 문단 Hit@k가 내려간다. 얼마나 내려가는지와 문헌 Hit@k(정답 문헌을 먼저 올리나)를 본다.
**종류**: 평가 범위 비교 (검색기는 그대로)
**바꾼 것 (하나)**: 줄마다 검색 범위. 정답 문헌 + 풀 문헌 중 우선일 전 공개·같은 특허 아님·비특허 아님 (범위 파일 기준 줄마다 노이즈 4~14건, 정답 포함 평균 10.6건. 풀은 색인에 있는 문헌만 골랐지만 조각 수는 문헌마다 다르다)

## 해석 (사람이 두세 줄)
- 노이즈를 섞으면 Hit@10이 0.618 → 0.353으로 거의 반이 된다. 무작위 대비 배수는 1.6배 → 6.8배로 커져, 문헌 안 점수가 무작위 기준선 때문에 쉬워 보이던 부분이 드러난다.
- 문헌 Hit@1 0.544: 1등 조각이 정답 문헌에서 나오는 줄이 절반 남짓이다. 노이즈 상위 오답 중 심사관이 안 짚었지만 관련 있는 문단이 있는지는 아직 사람이 안 봤다 (#178 T4).

## 하이브리드 둘째 점수 (재아 맥, 11/21)
재아 님 맥에서 `m2-i2-cite-search-hybrid-rrf`(RRF, cite-idx-v2) 설정에 `noise_scope: retrieval/cite_noise_b.jsonl` 한 줄만 더해 PR #199 브랜치(3346e09)로 돌린 값이다. 이 저장소에 scores.json은 없다 (재아 님 슬랙 보고). n=68, 비용 0.

| 지표 | 하이브리드 문헌 안 | 하이브리드 노이즈 B | BM25 노이즈 B (위) | 무작위 (노이즈 B) |
|---|---|---|---|---|
| Hit@1 | 0.162 | 0.118 | 0.044 | 0.006 |
| Hit@3 | 0.412 | 0.279 | 0.176 | 0.017 |
| Hit@5 | 0.574 | 0.294 | 0.265 | 0.028 |
| Hit@10 | 0.706 | 0.382 | 0.353 | 0.052 |
| Recall@10 | 0.508 | 0.244 | 0.233 | |
| 문헌 Hit@1 | (늘 1) | 0.588 | 0.544 | 0.096 |
| 문헌 Hit@10 | (늘 1) | 0.750 | 0.721 | 0.578 |
| CQ 후보 | 20 | 42 | 44 | |

- 노이즈 없이 다시 돌려도 0.706 그대로였고, `gold_sha256`·색인 지문·뺀 줄 수가 같았다 (재아 님 확인).
- 노이즈를 넣으면 하이브리드도 Hit@10이 거의 반(0.706 → 0.382)이 된다. BM25보다 Hit@10은 +0.03, Hit@1은 0.044 → 0.118로 앞선다.
