# AI 코어 (`src/patent_ai/core/`)
- 루트 CLAUDE.md "일하는 순서" 그대로: 구현 계획(tasks.md) → 테스트 먼저 → 구현.
- 부르는 방향은 `core → retrieval·law_api·db`만. `api`·`web`을 import하지 않는다 (ADR 0003 폴더).
- 결과 스키마(Pydantic)는 `schemas/`에. 이름은 docs/api/README.md 1절(결과 스키마 / 요청·응답 스키마 / DB 모델)을 따른다.
- 모델 호출은 `llm/`에서만. 모델 이름·회사는 단계마다 설정 파일(`config/`, 실험은 `experiments/<실험>/config.yaml`)에서 읽고 코드에 쓰지 않는다.
- 프롬프트는 `prompts/` 파일로. 코드 안에 긴 문자열로 두지 않는다.
- 서브에이전트와 그 도구는 각 기능 폴더(`f1_…`~`f4_…`) 안에. `agents/`는 지휘·근거 검토·공통 루프만.
- 테스트 밀도는 위치별: 답이 정해진 코드 도구(번호 정규화, 날짜 계산, 파싱, 청구항 비교, 초안 검사)와 꼭 지킬 선(사람 승인 전 멈춤, 누락 검사)은 촘촘히 테스트한다. AI 동작의 품질은 테스트가 아니라 tune 세트 점수로 본다. 프롬프트 문구는 테스트하지 않는다.
- 테스트는 가짜 결과 파일(`tests/fixtures/`)과 기록된 모델 응답으로. 네트워크·API 키 없이 돈다.
